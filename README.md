# Python Core

A structured collection of Python fundamentals, best practices, coding exercises, and mini projects.

The goal of this repository is to build a strong Python foundation for Data Engineering and software development.

## Topics Covered

- Variables
- Data Types
- Operators
- Strings
- Collections
- Loops
- Functions
- Modules
- File Handling
- Exception Handling
- OOP
- Iterators
- Generators
- Decorators
- Context Managers
- Type Hints
